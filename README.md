# BD2 Controller (브라운더스트 2 무한 뽑기 매크로)

브라운더스트 2(Brown Dust 2)의 튜토리얼/선별 무한 뽑기를 자동으로 진행해 주는 웹 UI 기반 매크로 프로그램입니다.
원하는 5성 코스튬 및 개수 조건을 만족할 때까지 뽑기를 반복하며, 디스코드를 통해 원격으로 결과를 확인하고 뽑기를 확정하거나 재시도할 수 있습니다.

---

## 1. 실행 방법 (Quick Start)

1. [Releases](../../releases) 탭에서 `BD2Controller_Release.zip`을 다운로드하고 압축을 풉니다.
2. 앱플레이어를 실행하고 게임의 무한 뽑기 화면에 진입합니다.
3. **`BD2Controller.exe`**를 실행합니다.
   - 최초 실행 시 **"Windows의 PC 보호"** 창이 뜨면 **[추가 정보] → [실행]**을 누릅니다.
4. 웹 브라우저가 열리며 컨트롤러 화면(`http://127.0.0.1:5000`)이 나타납니다.
5. 앱플레이어 포트와 목표 코스튬을 설정한 후 **[매크로 시작]**을 클릭합니다.

> **앱플레이어 권장 설정:**
>
> - 해상도: **1920x1080 (가로 모드, 240 DPI 권장)**
> - 기본 포트: LD플레이어 `5555`, MuMu 12 `16384`, 녹스 `62001`

## 2. 화면 구성 및 설정 가이드

### [탭 1] 무한뽑기 매크로

#### ① 기본 설정 (ADB & 시스템)

| 항목                   | 설명 및 설정 가이드                                                                                                   |
| :--------------------- | :-------------------------------------------------------------------------------------------------------------------- |
| **ADB 포트번호**       | 앱플레이어의 ADB 통신 포트 번호입니다. (LD: `5555`, MuMu: `16384` 등)                                                 |
| **클릭 딜레이**        | 가챠 버튼 클릭, 확인, 스킵 사이의 대기 시간(초)입니다. PC 사양에 따라 0.3~0.5초를 권장합니다.                         |
| **해상도 선택**        | 앱플레이어 화면 해상도를 선택합니다. 기본 제공되는 `FHD (1920x1080 - 240DPI)`를 선택하세요.                           |
| **이미지 인식 임계값** | 코스튬 이미지 일치 판별 기준(0.01 ~ 1.0)입니다. 기본값은 `0.80`이며, 오인식이 생기면 높이고 미인식이 많으면 낮춥니다. |

#### ② ADB 연결 및 인식 테스트

- **ADB 연결 테스트 / 해제**: 지정한 포트로 앱플레이어가 정상 연결되는지 사전에 확인합니다.
- **좌표 클릭 테스트**: X, Y 좌표를 입력하고 클릭이 제대로 들어가는지 화면을 테스트할 수 있습니다.

#### ③ 뽑기 & 코스튬 필터

- **최소 5성 개수**: 이번 뽑기 회차에서 나와야 하는 5성 코스튬의 전체 최소 수량입니다. (예: `2` 입력 시 5성이 2개 이상일 때만 정지)
- **희망 5성 개수**: 아래 등록한 '희망 코스튬' 목록 중에서 나와야 하는 최소 개수입니다.

#### ④ 희망 코스튬 설정

- **[+ 코스튬 추가]**: 목표로 노리는 5성 코스튬을 목록에서 선택하여 추가합니다.
- **필수 여부 체크**: 체크된 코스튬은 **반드시 나와야만** 매크로가 멈춥니다. (필수 코스튬이 하나라도 누락되면 최소/희망 개수를 채워도 계속 진행)

#### ⑤ 디스코드 봇 연동

목표 조건 달성 시 디스코드 채널로 결과 스크린샷과 획득 목록을 전송하고, 채팅이나 이모지로 원격 제어할 수 있습니다.

- **봇 토큰 / 채널 ID**: Discord Developer Portal에서 생성한 봇 토큰과 알림을 받을 채널 ID를 입력합니다.
- **알림 대상 유저 ID**: 멘션(`@유저`)을 받을 디스코드 사용자 ID (선택 사항).
- **원격 제어 방법**: 결과 알림 수신 후 디스코드 채팅에 `재시도`(또는 `1`), `종료`(또는 `2`)를 입력하거나 메시지의 `🔄` / `⏹️` 이모지 반응을 클릭하면 PC를 만지지 않고도 제어할 수 있습니다.

#### ⑥ 기타 부가 옵션

- **매크로 완료 시 PC 자동 종료**: 밤새 돌릴 때 목표 달성 후 60초 뒤 컴퓨터를 자동 셧다운합니다.
- **신규 코스튬 자동 추가**: DB에 없는 새 코스튬 감지 시 상세창을 열고 OCR로 판독하여 DB에 자동 등록합니다. (OFF 시 `unrecognized/` 폴더에 이미지만 보관)
- **서버 콘솔 디버그 모드**: 터치 좌표, 이미지 매칭 점수 등 개발/디버깅용 상세 로그를 출력합니다.
- **5성 코스튬 항상 OCR 테스트**: 5성을 감지할 때마다 정보창을 열어 OCR 검증을 수행하고 `ocr_test.log`에 기록합니다.

#### ⑦ 설정 저장 및 백업 복원

- **설정 저장**: 현재 입력된 설정을 `config.yaml`에 저장하며, 자동으로 `backup/` 폴더에 타임스탬프 백업을 남깁니다.
- **선택 백업으로 복원**: 이전에 저장했던 설정 시점을 선택하여 언제든지 설정을 되돌릴 수 있습니다.

### [탭 2] DB 데이터 관리

- **해상도 테이블 (resolutions)**: 게임 내 버튼 좌표, 결과 창 영역(ROI) 등 해상도별 좌표 데이터를 확인하고 추가합니다.
- **코스튬 테이블 (costumes)**: 현재 등록된 코스튬 이름, 성급, 템플릿 이미지 경로를 조회/수정/삭제합니다.
- **명칭 보정 (오탐) 관리**: OCR 판독 시 자주 발생하는 오타(예: `유스팀아` → `유스티아`)를 사전에 등록해 판독률을 보정합니다.
- **미인식 코스튬 수동 등록**: 자동 등록 옵션을 껐을 때 `unrecognized/` 폴더에 모인 이미지를 보고 이름과 성급을 수동으로 등록할 수 있습니다.

---

### 우측 제어 패널

- **현재 상태**: 중지됨 / 실행 중 상태를 실시간 표시합니다.
- **매크로 시작 / 중지**: 매크로 루프를 백그라운드로 실행하거나 즉시 중지합니다.
- **실행 로그**: 실시간 판독 결과, 조건 검증 통과 여부, 시스템 상태를 출력합니다.
- **OCR 로그 버튼**: 5성 코스튬 OCR 판독 테스트 결과(`ocr_test.log`)를 모달 창으로 바로 열람하거나 초기화합니다.

## 3. 소스코드 직접 실행 및 빌드 (개발자용)

```bash
# 의존성 설치
pip install -r requirements.txt

# 로컬 개발 서버 실행
python app.py

# 원클릭 배포 패키지 빌드 (dist/ 폴더 및 ZIP 생성)
build.bat
# 또는
python build_release.py
```
